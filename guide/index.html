준비

  • 개인 노트북과 전원 어댑터
  • 행사에서 안내한 AI 도구의 로그인 상태
  • 자동화하거나 더 빠르게 처리하고 싶은 작은 업무 하나
  • 공개 자료 또는 직접 만든 합성 예시

일정

시간 내용
0:00–0:30 강의, 라이브 데모와 사례 소개

팀 역할

5명 팀을 기준으로 하며 한 사람이 여러 역할을 맡을 수 있습니다.

역할 하는 일
드라이버 AI와 코드 도구를 직접 조작합니다.
네비게이터 해결할 문제와 다음 행동을 정합니다.
판정관 결과가 업무·도메인 기준에 맞는지 확인합니다.
크로스체커 다른 도구나 방법으로 결과를 대조합니다.
기록자 프롬프트, 수정 과정, 실행 방법과 한계를 정리합니다.

과제 트랙

트랙 A · 단일 페이지 업무 도우미

입력값을 넣으면 계산, 변환, 검사 또는 요약 결과가 나오는 작은 웹 도구를 만듭니다. 예: 측정불확도 계산기, 단위 환산기, 유효숫자 검사기.

트랙 B · 공개 측정 데이터 분석

data/의 공개 데이터로 현황 요약, 드리프트 탐색, 공백 분석 또는 그래프 생성 도구를 만듭니다.

트랙 C · 리서치 워크플로

공개 문헌이나 데이터베이스에서 조건·수치·근거를 수집해 비교표와 짧은 보고서를 만듭니다. 원문 링크와 인용 식별자를 결과에 남깁니다.

과제 축소 체크

다음 다섯 문항 중 네 개 이상에 예라고 답할 수 있어야 합니다.

데이터 규칙

등급 예 행동
GREEN 공개 자료, 교육용·합성 데이터 사용 가능
YELLOW 내부 구조를 반영한 데이터 공개 샘플이나 합성 데이터로 교체
RED 개인정보, 인증정보, 계약·보안 정보 외부 AI 입력 금지

판단이 어렵다면 사용하지 말고 합성 데이터로 바꿉니다.

제출물

  1. 작동 데모 — 작은 기능 하나가 실제로 실행되는 결과
  2. 작업 기록 — 무엇을 시켰고 어떻게 수정했는지 보여주는 기록
  3. 재현 메모 — 입력, 실행 방법, 필요한 환경과 남은 한계

발표

  • 1차 발표: 팀당 1분. 문제, 작동하는 결과와 가장 중요한 한계를 보여줍니다.
  • 최종 발표: 상위 4팀이 팀당 4분. 데모, 검증 방법, 실패 또는 한계와 다음 단계를 설명합니다.

작업 팁

  • 30분 동안 진전이 없으면 목표를 절반으로 줄입니다.
  • AI가 만든 수치는 코드로 다시 계산합니다.
  • 인용은 제목만 믿지 말고 원문 위치와 주장 범위를 확인합니다.
  • 같은 질문을 다른 도구나 팀원에게 주고 결과가 일치하는지 비교합니다.
