저장소 작성물

행사 문서, 정적 페이지와 변환 스크립트에는 현재 별도의 오픈소스 라이선스를 부여하지 않았습니다. GitHub에서 열람·포크할 수 있다는 사실만으로 별도의 재배포·상업 이용 권한이 부여되는 것은 아닙니다. 재사용 라이선스는 추후 명시적으로 결정합니다.

UCI 가스센서 데이터

data/gas_sensor_drift.csv는 UCI Machine Learning Repository의 Gas Sensor Array Drift Dataset을 교육용으로 변환한 파일입니다.

  • 원저자: Alexander Vergara 외
  • 원자료: UCI Dataset 224
  • DOI: 10.24432/C5RP6W
  • 라이선스: Creative Commons Attribution 4.0 International

재사용할 때 위 출처와 변환 사실을 함께 표시해야 합니다.

BIPM KCDB 데이터

data/kcdb_kriss_cmc.csv와 JSON 스냅샷은 공개 BIPM KCDB API 응답을 가공·보존한 것입니다. BIPM은 KCDB의 공개 접근과 API 제공을 명시하고 있습니다. 이 저장소는 그 사실을 넘어 원자료에 별도 오픈 라이선스가 부여됐다고 주장하지 않습니다.

재사용자는 BIPM의 최신 이용 조건을 확인하고 BIPM KCDB, CIPM MRA 출처와 스냅샷 날짜를 유지해야 합니다.

OpenAlex 메타데이터

demo/의 문헌 식별자, 제목, 초록 메타데이터와 인용 관계는 OpenAlex에서 가져온 자료를 포함합니다. OpenAlex는 데이터셋을 CC0로 제공합니다.

  • 서비스: OpenAlex
  • 조건: OpenAlex free data, CC0

OpenAlex 메타데이터의 공개 조건과 각 학술 논문 본문의 저작권은 구분해야 합니다. 이 저장소는 논문 전문을 배포하지 않습니다.

학술 자료

논문 제목, 식별자와 짧은 설명은 출처 식별과 교육적 논평을 위해 사용합니다. 원 논문의 저작권과 라이선스는 각 출판사와 저자에게 있습니다. 자세한 목록은 출처와 검증 범위를 참고하세요.
