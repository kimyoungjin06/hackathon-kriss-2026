# 가스센서 드리프트 교육 데이터

36개월 동안 16개 화학 센서를 6종 가스에 노출해 얻은 UCI Gas Sensor Array Drift Dataset의 교육용 변환본입니다. 시간에 따른 센서 응답 변화와 모델 성능 저하를 탐색하는 데 사용합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `gas_sensor_drift.csv` | 13,910행 × 37열 교육용 CSV |
| `prepare_gas_sensor_data.py` | 원본 libsvm 파일을 CSV로 변환하는 스크립트 |

## 주요 열

| 열 | 의미 |
|---|---|
| `batch` | 1~10의 시간 순서 배치 |
| `months` | 각 배치가 포함하는 측정 개월 |
| `gas`, `gas_ko`, `gas_no` | 가스 이름과 원본 클래스 번호 |
| `S01_dR` … `S16_dR` | 센서별 정상상태 저항 변화량 |
| `S01_dR_norm` … `S16_dR_norm` | 센서별 정규화 응답 |

원본은 센서당 8개 특징을 포함하지만, 이 파일은 입문 실습을 위해 정상상태 특징 2개만 남겼습니다. 전체 특징이 필요하면 변환 스크립트의 `--full` 옵션을 사용합니다.

## 시작 질문

1. 배치별로 센서 응답 분포가 어떻게 달라지는가?
2. 시간에 따른 변화가 큰 센서와 상대적으로 안정적인 센서는 무엇인가?
3. 초기 배치로 학습한 분류 모델의 정확도가 이후 배치에서 어떻게 달라지는가?
4. 표본 수와 가스 구성 차이가 관찰한 패턴을 만든 것은 아닌가?

## 해석할 때 주의할 점

- 배치별 표본 수와 가스 구성이 다릅니다.
- 일부 가스는 특정 배치에 존재하지 않습니다.
- 원본 배포본에는 각 측정의 농도 열이 포함되지 않습니다.
- 물리 단위와 측정불확도 정보가 충분하지 않아 엄밀한 측정학적 결론에는 적합하지 않습니다.
- 음수와 극단값이 있으므로 로그 변환이나 비율 계산 전에 분포를 확인해야 합니다.
