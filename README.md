# KRISS 화학소재측정본부 3시간 해커톤 (2026)

리조트 오프사이트에서 진행하는 3시간 바이브코딩 미니 해커톤 운영 자료.

## 확정 사항

- 대상: KRISS **화학소재측정본부** (가스측정·무기측정·유기측정·첨단소재·소재물성 5개 그룹)
- **규모 확정: 62명 · 5명씩 12팀** (2026-08-06 본부장 회신) — 기존 40명/10팀 가정에서 상향
- 참여 강도 자유: 직접 조작을 원치 않는 참가자(시니어 등)는 네비게이터/판정관 역할 — 팀 역할 3종 설계 (브리프 참조)
- 형식: 강의 30분(라이브 데모 + 쇼케이스 포함) → 팀 편성 10분 → 해킹 100분 → **12팀 × 1분 발표 → 현장 투표 → 상위 4팀 × 4분 발표** 40분(전환·시상 포함)
- 도구 3경로: ① 웹 챗(개인/무료 계정 — 미보유자 사전 가입 필수) ② 팀 API 키(하네스·Colab용, 팀당 1키+지출 한도) ③ 비조작 역할 참여
- 데이터: 실제 내부 데이터 반입 금지 — 신호등 규칙(GREEN/YELLOW/RED) 적용

## 미확정 (정해지면 문서 업데이트)

- 워크숍 일시·장소 (재확인 요청함)
- 원내 AI 사용 가능 수준 (보안 항목 5가지 회신 대기)
- 시상 규모 · 본부 측 심사위원
- 그룹별 연구 내용 (본부에서 다음 주 송부 예정)

## 확정된 진행 방식 (2차 회신 기준)

- 발표: **12팀 × 1분 → 현장 투표 → 상위 4팀 × 4분** (전환 포함 40분) → 실습 100분 확보
- 팀당 5명, 숙련자 1명을 팀장·멘토로 배치 (12팀 규모에서 운영의 전제 조건)
- GS MISO는 금번 생략, Codex·Claude Code 하네스 경험에 집중
- 실제 원내 데이터 미사용 원칙
