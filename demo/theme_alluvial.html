시기별 연구 테마는 인용으로 어떻게 연결되는가

혼합 코퍼스를 시기마다 독립적으로 클러스터링하고, 인용 연결(후속 시기 논문이 이전 시기 논문을 인용)로 이은 alluvial입니다. 리본은 시기별 클러스터 사이의 연결 강도이며, 한 테마가 다른 테마로 변했다는 동일성이나 인과를 뜻하지 않습니다. 테마에 마우스를 올리면 연결된 클러스터가 시기를 가로질러 켜지고, 클릭하면 대표 논문으로 내려갑니다.

← 테마 블록을 클릭하세요. 세로 크기 = 논문 수, 리본 = 인용 연결.

시기별 클러스터링 = BC(서지결합)+bge-m3 임베딩 융합특징 k-NN 그래프에 Leiden 커뮤니티 검출 — 클러스터 수를 데이터가 결정. 토글로 해상도(굵직/세밀) 전환. 리본 = 후속 시기 테마가 직전 시기 테마를 인용한 연결. 세로 크기 = 논문 수, 리본 폭 = 인용 수. 라벨은 대표 논문을 입력으로 LLM이 생성한 탐색용 명칭입니다. 논문 클릭 시 OpenAlex 레코드로 연결합니다.
